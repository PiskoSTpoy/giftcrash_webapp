# База знаний «Аркона»

Самостоятельная база знаний компании: структурированные Markdown-документы + лёгкий браузерный сайт для навигации и поиска. Без внешних зависимостей.

## Структура

```
knowledge-base/
├── arkona-baza-znaniy.html  # АВТОНОМНЫЙ файл: открыть двойным кликом, без сервера
├── index.html        # сайт базы знаний (требует локального сервера)
├── kb.css            # стили
├── kb.js             # навигация, роутинг, рендер Markdown, поиск
├── build-standalone.py      # сборка автономного файла из content/*.md
├── README.md         # этот файл
└── content/          # весь контент в Markdown (источник правды)
    ├── 00-home.md
    ├── people/       # Блок «Люди»: о компании, HR, KPI, обучение
    ├── processes/    # Блок «Процессы»: продажи, диспетчеризация, бухгалтерия
    ├── assets/       # Блок «Клиенты и техника»: автопарк, клиенты, поставщики
    └── management/   # Блок «Управление»: финансы, шаблоны, стратегия
```

Навигация построена по принципу **4 блока × 12 разделов** (гибрид детальной и укрупнённой структуры) с дополнительным разрезом по отделам (ОП, ТО, ДО, ОБ, HR, СБ).

## Как открыть

### Вариант 1 — один файл (проще всего)
Откройте **`arkona-baza-znaniy.html`** двойным кликом. Все разделы заранее отрисованы в HTML — файл **не требует JavaScript, сервера и интернета**, поэтому открывается в любом браузере и в превью на телефоне (iPhone/Android). Навигация — по «Содержанию», поиск — встроенный в браузер (Ctrl/Cmd+F). Пересобрать после правок контента:

```bash
cd knowledge-base
python3 build-standalone.py   # пересоздаёт arkona-baza-znaniy.html
```

### Вариант 2 — сайт с отдельными файлами
`index.html` загружает Markdown через `fetch`, поэтому его нужно открывать **через локальный сервер** (не двойным кликом):

```bash
cd knowledge-base
python3 -m http.server 8000
# открыть http://localhost:8000
```

Либо опубликовать папку через GitHub Pages / любой статический хостинг.

## Как читать и дополнять

- Источник правды — файлы `content/**/*.md`. Их можно читать прямо на GitHub.
- Markdown легко импортируется в **Notion, Confluence, Битрикс24** при масштабировании.
- Метки статуса в документах: **Готово** / **Черновик** / **Каркас**.
- Блоки-цитаты со словом **«Заполнить»** — места для данных компании (телефоны, госномера, карточки, суммы).
