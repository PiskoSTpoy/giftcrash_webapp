# Как открыть базу знаний с доступом по паролю и с телефона (Windows)

Ваш компьютер раздаёт базу, а бесплатный туннель Cloudflare даёт `https`-ссылку,
которую можно открыть с любого телефона. Доступ закрыт логином и паролем.

> ⚠️ Это вариант для пилота/предпросмотра. Компьютер должен быть **включён**.
> Для постоянной работы лучше перенести базу на ваш сервер.

## Что нужно один раз подготовить

1. **Установить Python**
   - Скачать: https://www.python.org/downloads/
   - При установке поставить галочку **«Add Python to PATH»**.

2. **Скачать cloudflared (один файл)**
   - https://github.com/cloudflare/cloudflared/releases/latest
   - Скачать `cloudflared-windows-amd64.exe`, переименовать в **`cloudflared.exe`**
   - Положить рядом с этим файлом (в папку `serve/`).

3. **Задать пароль**
   - Открыть `kb-server.py` блокнотом, в начале поменять `LOGIN` и `PASSWORD`.

## Как запускать каждый раз

1. Дважды кликнуть **`start-windows.bat`**.
2. В чёрном окне появится ссылка вида `https://xxxx.trycloudflare.com`.
3. Отправить эту ссылку сотрудникам / открыть на телефоне.
4. Браузер спросит логин и пароль — ввести те, что задали в `kb-server.py`.

Готово — база открывается на телефоне, с паролем.

## Остановить
Закрыть оба окна: чёрное окно туннеля и окно **«KB server»**.

## Частые вопросы
- **Ссылка меняется при каждом запуске.** Да, бесплатный быстрый туннель даёт новый
  адрес. Для постоянного адреса — аккаунт Cloudflare/ngrok или хостинг на вашем сервере.
- **Никто не может зайти.** Проверьте, что оба окна открыты и компьютер не ушёл в сон.
- **Хочу без интернета, только по офису.** Тогда cloudflared не нужен: запустите
  `python kb-server.py` и открывайте `http://АДРЕС-ВАШЕГО-ПК:8000` в той же сети.
