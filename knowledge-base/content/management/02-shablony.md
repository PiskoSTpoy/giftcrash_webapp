## Чек-листы
| Чек-лист | Когда применяется |
|----------|-------------------|
| Выход нового сотрудника | Онбординг (см. [HR](#people/02-hr-i-naem)) |
| Передача клиента | От коммерческого директора менеджеру |
| Закрытие заказа | Заявка → подача → акт → оплата |
| Качество заявки | Звонок → подача → работа → закрытие |
| Закрытие месяца | Финансы/документы/отчётность |

> **Заполнить.** Развернуть каждый чек-лист в пошаговый список с ответственными и сроками.
