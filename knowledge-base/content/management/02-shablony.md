## Обходной лист нового менеджера по продажам

> **Статус: Готово (из документов компании).** Заполняется при вступлении в должность. Ответственный — РОП (Макарова Надежда Викторовна).

**ФИО:** `__________________________`  **Дата выхода:** `__________`

**Рабочее место**
- [ ] Рабочий стол
- [ ] Кресло на колёсиках
- [ ] Рабочий компьютер
- [ ] Мобильный рабочий телефон (выдаёт РОП)

**Телефон и прослушка**
- [ ] Подключено прослушивание звонков от Билайн
- [ ] WhatsApp: рабочие чаты не менее 30 шт. (запрос приглашений у админов чатов по шаблону: «Добрый день, меня зовут ___, я новый менеджер компании Аркона (парк более 50 единиц техники), пришлите, пожалуйста, приглашение в вашу группу»). Список чатов — у РОПа.

**Добавление в общие чаты компании (Telegram):**
- [ ] Аркона самосвалы заявки (распределение заявок на самосвалы)
- [ ] Аркона кухня (общий чат компании)
- [ ] Аркона Машины (распределение своих самосвалов)
- [ ] Аркона путевые (путевые листы самосвалов)
- [ ] Приходы (приходы от заказчиков по банковской выписке)
- [ ] АРКОНА ИНФА (схемы проезда, карточки компаний)
- [ ] Ковш и Молот (чат по спецтехнике)

**WhatsApp:**
- [ ] АРКОНА не закрытые заявки (взаимопомощь по закрытию заявок)

**Доступы и оформление**
- [ ] Рабочая почта — создать, дать доступ, подключить
- [ ] Общий рабочий диск — подключить, дать доступ
- [ ] Рабочий пропуск на территорию организации
- [ ] Внести сотрудника в телефонный справочник организации
- [ ] Создать аккаунт в Битрикс24 для ведения клиентов
- [ ] Выделить новый платёжный номер (#__)
- [ ] Заполнить анкету сотрудника, передать офис-менеджеру (кадровику) в архив
- [ ] Завести в финотдел дату первого дня для зарплаты
- [ ] Копии/ксерокопии паспорта
- [ ] Договор ГПХ — составить и заключить
- [ ] Знакомство с отделом бухгалтерии

> **Заполнить.** Развернуть остальные чек-листы (передача клиента, закрытие заказа, качество заявки, закрытие месяца) в пошаговые списки с ответственными и сроками. Сделать аналогичные обходные листы для других ролей.
