# 13. Финансы

> **Статус: Готово (v1).** *Закрывает проблемы: «нет грамотного управления финансами», «нет бюджетирования».*

Стратегический ориентир — **рост собственного денежного потока без зависимости от заёмных средств**.

---

## 13.1. Финансовая модель компании

### Источники дохода
- Аренда спецтехники (собственный парк) — цель **292 млн ₽/год**.
- Аренда наёмной техники (маржа подрядчика).
- Комплексные услуги «под ключ» (земляные работы, вывоз грунта/снега, демонтаж, логистика).
- Филиал СПб — цель чистая прибыль **2 млн ₽/мес**.

### Основные расходы
- ФОТ и мотивация.
- Топливо, ТО, ремонт, страховки техники.
- Оплата подрядчиков (наёмная техника).
- Маркетинг (Авито, SEO, Директ).
- Аренда офиса, ПО (1С, CRM), накладные.

### Целевые показатели 2026
| Показатель | Цель |
|-----------|------|
| Выручка | 476 млн ₽/год |
| Валовая маржа | 184 млн ₽/год |
| Дебиторка | ≤ 200 млн ₽ |
| Резервный фонд | 5% от чистой прибыли |

## 13.2. Дебиторская задолженность
> *Цель — удерживать ≤ 200 млн ₽.*

### Регламент контроля
- **Матрица ответственности по дебиторке:** кто ведёт, кто напоминает, кто закрывает.
- Авто-напоминания клиентам по оплатам.
- **Еженедельный разбор просрочек** + персональная ответственность менеджера.
- Жёсткая политика по новым клиентам: **лимиты** и проверка (СБ).

### Алгоритм взыскания
1. Авто-напоминание за N дней до срока.
2. Звонок менеджера в день просрочки.
3. Официальное письмо/претензия.
4. Эскалация руководителю / СБ / юристу.

> **Заполнить.** Точные лимиты по сегментам, сроки эскалации, шаблоны писем (см. [Шаблоны](#management/02-shablony)).

---

## 13.3. Бюджетирование и планирование
- **Cash-flow на 3 месяца вперёд** + финансовый календарь.
- Помесячное планирование выручки по продуктам: техника, спецкар, краны, СПб.
- Анализ отклонений план/факт — еженедельно (выручка, маржа), ежеквартально (стратегия).
- **Резервный фонд:** фиксировать 5% от чистой прибыли, расходование — только с согласования.
- Отдельный **P&L по собственной технике**.

> **Заполнить.** Бюджет на год по статьям, шаблон план/факт, регламент использования резервного фонда.

## 13.4. Рекомендации по управлению финансами (из стратсессии)

**Выручка 476 млн ₽/год (+45%):**
- помесячное планирование выручки по продуктам (техника, спецкар, краны, СПб);
- еженедельный контроль выполнения плана и корректировки по загрузке парка;
- структура ассортимента 80/20 (какие машины дают основную выручку) — приоритет загрузки на них;
- еженедельный анализ спроса по сегментам (жильё, промышленность, энергетика, реновация).

**Валовая маржа 184 млн ₽/год:**
- цифровое планирование себестоимости каждой единицы техники;
- контроль маржи по каждому заказчику и виду техники;
- правило: заявки с маржой **< 15% — через согласование руководителя**;
- пересмотр тарифов в сегментах, где маржа падает.

**Собственная техника — 292 млн ₽/год:**
- отдельный **P&L по собственной технике**;
- KPI диспетчерам по загрузке собственного парка;
- фиксация % загрузки в CRM в реальном времени (план/факт).

**Дебиторка ≤ 200 млн ₽:**
- матрица ответственности (кто ведёт, напоминает, закрывает);
- авто-напоминания клиентам; еженедельный разбор просрочек; персональная ответственность менеджера;
- жёсткая политика лимитов по новым клиентам.

**Филиал СПб — прибыль 2 млн ₽/мес:**
- локальное управление (руководитель + ассистент); локальный маркетплан (строители, энергетика, реновация);
- 80% операций — по процессам Москвы (документооборот + CRM); еженедельные KPI: выручка, маржа, дебиторка, загрузка парка.
