# 5. База обучения (Корпоративный университет)

> **Статус: Готово (v1).** Структура курсов — по образцу отраслевой LMS (категории = отделы, внутри — нумерованные модули с тестированием). *Закрывает задачу стратсессии: «Создать корпоративный университет — База знаний».*

Принцип: **«Мы растём не только деньгами, но и мозгами»** — рост IQ каждого сотрудника как топливо компании.

---

## Как устроено обучение

- Обучение разбито на **курсы по отделам**; внутри курса — нумерованные модули.
- Каждый модуль завершается **тестированием**.
- Прогресс фиксируется; по итогам — аттестация и план развития.

### Карта курсов по отделам

| Отдел | Курс (онбординг + развитие) |
|-------|------------------------------|
| Общий (до начала) | Кодекс и ценности, презентация для новых, охрана труда |
| Отдел продаж (ОП) | Знакомство с ОП, продукт и УТП, скрипты, работа с возражениями, CRM |
| Диспетчеризация/Транспорт (ТО) | Виды техники, алгоритм заявки, подбор техники, 1С |
| Документооборот (ДО) | Закрывающие документы, сроки, 1С |
| Бухгалтерия (ОБ) | Первичка, 1С, НДС/налоги |
| Руководители (ТОР) | Управление, планёрки, KPI, дашборды |

### Пример онбординг-курса «Знакомство с Отделом продаж»
1. 1.1 — Кодекс и ценности «Арконы»
2. 1.2 — Презентация для новых сотрудников
3. 1.3 — План стажировки
4. 1.4 — Карьерный рост в отделе продаж
5. 1.5 — Должностная инструкция менеджера
6. 1.6 — Тестирование №1
7. 2.1 — Обучающий курс по CRM (Битрикс24)
8. 2.2 — Интерфейс и воронки в CRM

## 5.1. Спецтехника (база знаний по технике)
Виды техники и для чего используется:

| Категория | Техника | Назначение |
|-----------|---------|-----------|
| Землеройная | Экскаваторы, погрузчики | Котлованы, траншеи, погрузка |
| Грузоподъёмная | Краны, манипуляторы | Подъём и перемещение грузов |
| Дорожная | Катки, асфальтоукладчики, грейдеры | Дорожное строительство |
| Логистика | Самосвалы, длинномеры, тралы | Перевозка грунта, материалов, негабарита |
| Коммунальная | Илососы, каналопромывочные, КДМ, МТЗ | Городские/коммунальные задачи, уборка снега |

> **Заполнить.** Добавьте по каждому типу: фото, технические характеристики, типовые задачи, требования к оператору, частые ошибки эксплуатации.

## 5.2. Строительство (отраслевая грамотность)
> **Заполнить.** Основные процессы стройки (котлован → благоустройство → дорожки → инженерка), термины, этапы объекта, кто такие девелопер / генподрядчик / застройщик / субподрядчик — чтобы менеджер говорил с клиентом на одном языке.

## 5.3. Продажи (развитие навыков)
- Скрипты продаж и работа с возражениями (см. [Продажи](#processes/01-prodazhi)).
- Обучение 1С и Excel для отчётности.
- Видео-инструкции по процессам.
> **Заполнить.** Список книг, видеоуроков и разбор реальных кейсов компании (выигранные крупные сделки, сложные объекты).
