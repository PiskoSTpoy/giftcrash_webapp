# 4. KPI компании

> **Статус: Готово (v1).** Целевые значения — из стратегических целей на 2026 г. Персональные нормы менеджеров — из блока «10 первых шагов».

KPI отвечают на вопрос «какие показатели определяют результат» для каждой роли. Один сотрудник — понятный набор измеримых показателей.

---

| Показатель | Цель 2026 | Комментарий |
|-----------|-----------|-------------|
| Выручка | **476 млн ₽/год** (36,34 млн/мес) | +45% к 2025 г. |

## 4.1. Собственник
- Выручка
- Валовая прибыль / маржа
- EBITDA
- Чистый денежный поток (рост собственного, снижение заёмного)

## 4.2. Коммерческий директор
- Новые крупные клиенты (wishlist: ОЭК, МВК, ТМГ, ДиМ, А-101 — 5 шт. по ~20 млн)
- Объём продаж / выполнение плана выручки
- Маржинальность по сегментам

## 4.3. РОП
- Выполнение плана продаж отделом
- Дебиторская задолженность отдела (≤ целевого уровня)
- Конверсия воронки: контакты → встречи → заявки → деньги
- Дисциплина KPI менеджеров (контроль ежедневный)

## 4.4. Менеджер (МОП)
| KPI | Норма |
|-----|-------|
| Холодные звонки | **30–50 в день** |
| Новые контакты | **5–10 в день** |
| Встречи (вкл. онлайн) | **1 в день** |
| Новые клиенты | по личному плану (вклад в +15) |
| Маржа по своим сделкам | ≥ целевой |
| Фиксация действий в CRM/1С | 100% |
| Сдача закрывающих документов | в срок (24 ч) |

## 4.5. Диспетчер
- Маржинальность заявок
- Скорость закрытия заявок (время приём → подача)
- **Загрузка собственного парка** (план/факт, % в реальном времени)
- Доля закрытых «висящих» заявок

## 4.6. Маркетолог
- Количество лидов по каналам (Авито, SEO, Директ)
- Стоимость лида (CPL)
- Конверсия лид → заявка

## 4.7. Документооборот / Бухгалтерия
- Доля документов, сданных в срок
- Отсутствие ошибок в первичке и 1С
- Своевременность оплаты подрядчикам
