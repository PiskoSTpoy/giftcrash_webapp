## 12.2. Рейтинг поставщиков
Оценка по критериям (1–5):

| Критерий | Описание |
|----------|----------|
| Надёжность | Соблюдение сроков подачи, отсутствие срывов |
| Качество техники | Состояние, возраст, оператор |
| Долги/финансовая дисциплина | Наличие задолженностей, спорных ситуаций |
| Документооборот | Своевременность и корректность закрывающих |

> **Заполнить.** Проставить рейтинги; вести «белый» и «чёрный» списки. Проверка надёжности — обязательна перед первым заказом (СБ).

## 12.3. Маржинальность наёмной техники
- Цена клиента − цена подрядчика = маржа; цель ≥ 15%.
- Заявки с маржой < 15% — согласование руководителя.
- Своевременная оплата подрядчикам по единому регламенту (см. [Бухгалтерия](#processes/03-buhgalteriya)) — условие долгосрочного партнёрства.
