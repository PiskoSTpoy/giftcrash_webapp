## 9.3. Экономика техники
> *Закрывает задачу стратсессии: «цифровое планирование себестоимости каждой единицы техники», отдельный P&L по собственному парку.*

- **Себестоимость часа** = топливо + амортизация + ФОТ водителя + ремонт/ТО + страховка + накладные.
- **Минимальная цена продажи** = себестоимость + целевая маржа (≥ 15%).
- **План загрузки** парка (KPI диспетчера, факт в CRM в реальном времени).

> **Заполнить.** Калькулятор себестоимости по типам техники; целевой % загрузки; P&L собственного парка (цель 292 млн ₽ выручки/год).
